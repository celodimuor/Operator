# Observability standard

| Area | Rule | Enforcement |
|---|---|---|
| Logs | Structured; every line carries `account_id` and request or job id where available; no PII or secrets | review, gitleaks |
| Traces | OpenTelemetry via the existing core instrumentation concern; spans for every service `call`, job, webhook and provider call | review |
| AI traces | OpenTelemetry `gen_ai.*` spans exported to Langfuse; PII redacted first | `operator-specs` (AI) |
| AI cost | Tokens and cost persisted per run and run step in the database | `operator-specs` |
| Metrics | Each new behaviour emits rate, error and duration metrics | review (Definition of Done item 8) |
| Dashboards and alerts | Each new behaviour ships with a dashboard panel and an alert | review |
| SLO alerts | Multi-window burn-rate alerts on the SLOs in performance.md | review |
| Collection | CloudWatch plus an OpenTelemetry collector (af-south-1) | Terraform review |
| Errors | Sentry (pending account creation) | review |
| Events | Domain events named `operator.<module>.<past_tense_verb>`; catalogue generated (dispatcher, webhook, cable) | registry spec, `docs` |
| Jobs | Job catalogue generated by reflection (queue, schedule, retries, idempotency key) | `docs` |
| Cost report | Weekly generated cost report (infra and AI) | scheduled |
| Nightly evals | AI scorecards written per pack | nightly |
